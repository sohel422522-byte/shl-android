# SHL Downloader — নেটিভ Android অ্যাপ (Developed by MD Sohel)

ফোনের ভেতরেই yt-dlp + ffmpeg চলে — কোনো সার্ভার, পাসওয়ার্ড বা PWABuilder লাগে না।
ফোনের নিজের ইন্টারনেট ব্যবহার হয়। ভিডিও সবসময় **MP4**, অডিও সবসময় **MP3**।

## কী কী আছে
- **Share → SHL Downloader** (Facebook/YouTube অ্যাপ থেকে সরাসরি), অথবা লিংক পেস্ট
- কপি করা লিংক নিজে ধরে (উপরে "📋 কপি করা লিংক" বার → **ব্যবহার করুন**)
- ⚡ দ্রুত MP4 · 🎚 কোয়ালিটি বাছুন (সেরা/2160/1440/1080/720/480/360) · ♫ MP3
- একাধিক লিংক একসাথে (প্রতি লাইনে একটা)
- ব্যাকগ্রাউন্ডে ডাউনলোড + নোটিফিকেশন, প্রগ্রেস, বাতিল, "খুলুন"
- সেভ হয়: ভিডিও → `Movies/SHL Downloader`, MP3 → `Music/SHL Downloader` (গ্যালারি/মিউজিক অ্যাপে দেখা যায়)
- 📁 **সেভ ফোল্ডার** বাটনে নিজের পছন্দের ফোল্ডার বেছে নেওয়া যায়
- 🔄 **ইঞ্জিন আপডেট** (yt-dlp প্রতিদিন নিজেও আপডেট হয়)
- Android 10 বা তার পরের ফোন দরকার

## APK বানানো (নিজের কম্পিউটারে কিছু ইনস্টল লাগবে না — GitHub বানিয়ে দেবে)
1. github.com → **New repository** → নাম `shl-android` → Create।
2. **uploading an existing file** → এই zip আনজিপ করে ভেতরের **সব ফাইল ও ফোল্ডার** ড্র্যাগ করুন → **Commit changes**।
   - যদি `.github` ফোল্ডারটা আপলোড না হয় (লুকানো ফোল্ডার): **Add file → Create new file** → নামের ঘরে লিখুন
     `.github/workflows/build-apk.yml` → `build-apk.yml` ফাইলের লেখা পেস্ট করুন → Commit।
3. **Actions** ট্যাব → **Build APK** → **Run workflow** (প্রথমবার ১০–২০ মিনিট লাগতে পারে)।
4. সবুজ টিক এলে ওই রান খুলে নিচে **Artifacts → SHL-Downloader-APK** ডাউনলোড করুন → আনজিপ → `app-debug.apk`।
5. ফোনে APK ইনস্টল করুন ("অজানা সোর্স থেকে ইনস্টল" Allow দিতে হবে)।

## প্রথমবার চালানোর সময়
- নোটিফিকেশনের অনুমতি **Allow** দিন।
- নিচে "ইঞ্জিন প্রস্তুত ✓" না আসা পর্যন্ত কয়েক সেকেন্ড অপেক্ষা করুন (ইন্টারনেট থাকতে হবে, yt-dlp আপডেট হয়)।

## সমস্যা হলে
- **বিল্ড লাল ❌ হলে:** ব্যর্থ রান খুলে লাল এরর লাইনগুলো কপি করে আমাকে পাঠান — ঠিক করে দেব।
- **YouTube কাজ না করলে:** আগে 🔄 ইঞ্জিন আপডেট চাপুন। তাতেও না হলে GitHub-এ `gradle.properties` ফাইল খুলে
  `ytdlVersion=0.17.+` কে `ytdlVersion=0.18.+` করুন → Commit → আবার বিল্ড করুন।
- **"সাইন-ইন চাইছে":** মোবাইল ডেটা ↔ ওয়াইফাই বদলে দেখুন।
- **সীমাবদ্ধতা:** লগইন লাগে এমন ভিডিও (Facebook Stories, প্রাইভেট) হবে না। APK-র সাইজ নিচের “সাইজ” অংশে দেখুন।
  Play Store-এ তোলা যাবে না। অন্যকে APK দিলে ব্যবহৃত লাইব্রেরির (GPL) নিয়ম মানতে হবে।
- শুধু নিজের বা অনুমতি আছে এমন কনটেন্ট নামান।

## সাইজ ও ফোনের গতি
- APK-র প্রায় পুরোটাই ভেতরের ইঞ্জিন (Python + yt-dlp + ffmpeg)। এটা ছাড়া ফোনে সরাসরি ডাউনলোড সম্ভব না।
- ডিফল্টে এখন শুধু **arm64-v8a** (২০১৭-র পর বানানো প্রায় সব ফোন) বানানো হয় — আগের চেয়ে প্রায় অর্ধেক। আসল সাইজ বিল্ড শেষে Actions-এর **Summary** পাতায় "APK size" লাইনে দেখাবে।
- খুব পুরোনো ৩২-বিট ফোনে "App not installed" এলে: **Actions → Build APK → Run workflow** → CPU types ঘরে `arm64-v8a,armeabi-v7a` লিখে চালান।
- APK-র সাইজ ফোনের গতি কমায় না, শুধু জায়গা নেয় (ইনস্টলের পর প্রায় দ্বিগুণ, কারণ ইঞ্জিন খুলে রাখা হয়)।
  ডাউনলোড না চললে অ্যাপ কিছুই চালায় না; ডাউনলোডের সময় সামান্য RAM/CPU লাগে।
